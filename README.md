

# ML Pipeline — Student Performance Prediction

## Overview
A complete machine learning pipeline to predict students' final grades (G3) using academic and socio-demographic features.

## Dataset
- **Source:** UCI Machine Learning Repository — Student Performance Dataset
- **Target variable:** G3 (final grade)

## Models Compared
| Model | Metrics |
|---|---|
| Linear Regression | MAE, RMSE, R² |
| Decision Tree | MAE, RMSE, R² |
| Neural Network (MLP) | MAE, RMSE, R² |

## Pipeline Steps
1. Data loading and exploration
2. Preprocessing — encoding categorical variables + normalization
3. Model training and evaluation
4. Results comparison and interpretation

## Technologies
- Python
- pandas, numpy
- scikit-learn (Pipeline, ColumnTransformer, StandardScaler, OneHotEncoder)
